- A Question that turns out unavailable at answer time (`409 QUESTION_UNAVAILABLE` / `PENDING_IN_TODAY`, `404`) is skipped neutrally on the client and not counted.
- Practice never sends or accepts confidence, user id, session id, plan/item id or answer time.
