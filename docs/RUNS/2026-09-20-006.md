## Handoff Summary

An authorized OWNER or active INSTRUCTOR can now manually create a
SINGLE_CHOICE or MULTIPLE_CHOICE Question in a Course, associate it with a
Topic from that same Course, save/edit its draft, explicitly publish it as
an immutable QuestionVersion, and later edit/re-publish without changing
any historical version or Attempt reference. Draft-only Questions are
excluded from learner eligibility by construction (every existing
learner-facing/New-Material query already gates on
`current_version_id is not null`). No separate `QuestionDraft` table was
introduced (Run 005's carried-forward decision, reconfirmed). See
`docs/DEV_STATUS.md`'s "Question Authoring & Publishing" section for full
current-state detail — not duplicated here.
