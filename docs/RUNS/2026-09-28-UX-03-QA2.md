## 2. What changed (combined diff `8f45cc3..3272582`, 14 files, +889/-170)

- **Learn Mode** (`src/app/(learner)/today/question-card.tsx` + new test): post-submit layout reordered to Question → feedback/explanation → annotated options → sticky Continue, in normal document flow (no overlay). Correctness always paired with text/icon, never color alone; `selectedIncorrect` uses the calm amber `--state-reinforce` tokens (never `--danger`); `missedCorrect` carries an explicit "this was correct" label. - **Progress** (`src/app/(learner)/progress/page.tsx` + new `course-section.tsx`) and **Courses** (`src/app/(learner)/courses/page.tsx` + new `course-row.tsx`): each Course card is now a single real `<Link>` per `<li>` (no nested interactive controls), with hover/focus/pressed states and a subtle activity/role-derived accent, reusing existing tokens. Progress confirmed still Course-level only — no Topic-list rendering added or restored. The two components were extracted to sibling files because Next.js's `page.tsx` route-type generation rejects extra named exports — a framework constraint, not scope creep.
- **Authoring** (`src/app/instructor/courses/[courseId]/page.tsx` + new `question-row.tsx`): Question rows now use the existing `StatusPill` primitive for Draft/Published state and a `divide-y` row layout (mirroring an existing learner-side convention). Confined to one rendering hunk; bulk-select/bulk-publish/edit/import logic verified byte-identical outside that hunk.
- **Author-can-learn-own-Course**: not implemented. `course_memberships` has `UNIQUE(user_id, course_id)` plus a scalar `role` column (confirmed against the migration, ADR-015, `join-course.ts`/`ports.ts createMembership`, and both `hasActiveLearnerMembership`/`isPracticeEligible`) — an Author's OWNER row cannot coexist with a LEARNER row on the same Course without a schema change.
