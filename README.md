# UNLOCK

UNLOCK is a Hebrew-first, RTL-first adaptive learning application.

The product builds a learner model over time and uses it to decide the next best learning action.

## Core V1

- User
- Course
- Material
- Question
- Attempt
- UserQuestionProgress
- Exam Date
- Learner State
- Next Best Action
- Today Session
- Today Session Items
- Quiz
- Basic Progress

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- PostgreSQL / Supabase
- Vercel
- GitHub
- Cursor
