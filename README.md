# UNLOCK

UNLOCK is a Hebrew-first, RTL-first adaptive learning application.

The product builds a learner model over time and uses it to decide the next best learning action.

## Core V1

- Learner State
- Next Best Action
- Today
- Quiz
- Attempts
- UserQuestionProgress
- Exam Date
- Basic Progress

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- PostgreSQL / Supabase
- Vercel
- GitHub
- Cursor
